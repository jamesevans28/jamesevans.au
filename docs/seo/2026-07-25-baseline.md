# SEO baseline — 25 July 2026

First run of the `seo` skill, recorded as the baseline for future trend
comparison. The site and the Search Console property are both new, so low
numbers are expected — this document exists to make the _next_ run
meaningful, not to judge performance.

Window: 28 days (GA4), 90 days probed (Search Console).

## Access

All three API surfaces verified working via the `seo-agent` service account
(`npm run seo -- auth` → 3/3 ok). GA4 access is Editor; Search Console is
Full user on `sc-domain:jamesevans.au`.

Traffic sources: 30 sessions direct, 2 google/organic, 3 unset. Direct
dominance is consistent with a site shared by hand rather than found.

Geography: Australia 26.3% of users (5 of 19). Netherlands 4, Poland 3,
United States 3 — at this volume that mix is likely bots and incidental
traffic rather than a real audience signal. **Australia share is the KPI to
watch**; treat 26% as the starting line, not a verdict.

Early read worth revisiting once volume justifies it: `/services/` holds
attention longest (106s) and `/about/` has the highest engagement rate
(83%) but the shortest visit (27s) — consistent with `/about/` being a
quick credibility check on the way elsewhere. Do not draw conclusions from
2–4 users per page.

## Search Console

**Zero impressions and zero clicks across 90 days.** The property was only
just created, so no historical data has accumulated. Expected.

The substantive finding is indexing, not data volume:

| URL                                           | Index state                                                       |
| --------------------------------------------- | ----------------------------------------------------------------- |
| `/`                                           | Submitted and indexed; last crawled 15 Jul 2026, canonical agrees |
| `/blog/`                                      | **URL is unknown to Google**                                      |
| `/blog/why-ai-sounds-so-sure-when-its-wrong/` | **URL is unknown to Google**                                      |

The last crawl of the homepage predates the blog launch, and no sitemap had
ever been submitted, so Google had no path to the blog at all.

**Action taken:** submitted `https://jamesevans.au/sitemap.xml` via the API.
Accepted with 8 URLs, 0 errors, 0 warnings, not pending. Expect Google to
begin crawling the blog within days; verify at the next run with
`gsc inspect` on the two blog URLs above.

## Technical audit

11 pages, **0 errors**, 8 warnings. Nothing structural is broken:
canonicals, `robots.txt` (AI crawlers allowed), sitemap consistency, JSON-LD,
image alts, and the internal link graph all pass — no orphans, no broken
links.

Outstanding warnings:

- Home `<title>` is 73 chars — will truncate in results (aim 50–60).
- Meta descriptions over 158 chars on `/`, `/blog/`, `/experience/`,
  `/services/`, `/work/` (worst: `/` at 249).
- `/blog/` skips h1 → h3.
- Blog post title 62 chars (marginal; reads well, low priority).

## Core Web Vitals (PageSpeed, desktop, `/`)

Performance **99**, SEO **100**, LCP 0.3s, CLS 0.001, TBT 40ms. Comfortably
inside all thresholds. No CrUX field data yet — traffic is too low for
real-user measurement, so these are lab figures.

## Recommended next actions

1. **Verify the sitemap worked** — re-inspect the two blog URLs next run. If
   they are still unknown to Google in a week, investigate rather than
   resubmit.
2. **Fix the meta descriptions and home title** — cheap, and they control
   how the pages present once impressions start arriving.
3. **Leave the Australia share alone for now.** At 19 users it isn't a
   signal. Revisit once there is organic traffic to shape.
