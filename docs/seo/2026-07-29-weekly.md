- `why-chatgpt-never-recommends-your-business` — **Submitted and indexed**
  (was "unknown to Google" on 27–28 Jul)
- `ai-tax-return-what-its-good-for` — **Submitted and indexed** (same
  reversal, now resolved)
- `why-ai-sounds-so-sure-when-its-wrong` — **Submitted and indexed**,
  crawled yesterday (28 Jul)
- `ai-read-contract-before-signing` — **Submitted and indexed**
- `ai-insurance-complaint-letter` — **Submitted and indexed**
- `ai-not-relevant-to-my-business` — **Discovered — currently not
  indexed**. This is a normal, unremarkable state (Google knows the URL
  exists, hasn't crawled/indexed it yet) — not the "unknown to Google"
  failure state from earlier in the week.
- Homepage (`/`) — **Submitted and indexed**, though its last crawl is
  15 Jul (stale relative to the blog posts, unsurprising for a page that
  changes less).

So the sitemap's submitted/indexed rollup (13/0) is a lagging, unreliable
aggregate — per-URL `gsc inspect` is the ground truth, and it now shows the
site is indexed. Worth remembering for future runs: don't treat the sitemap
rollup as current-state evidence once individual inspections disagree with
it.

**The constraint has moved one stage down the funnel**: from _not indexed_
to _indexed but essentially no impressions yet_. GSC now shows real
impressions for the first time (2 queries, impressions on 6 pages, positions
ranging from 2 to 33), but 0 clicks throughout and only 1 AU-specific query
row. This is exactly the "indexed but not yet ranking meaningfully" stage —
optimising CTR or titles further would be premature; the real lever now is
patience plus more indexed, query-relevant content.

Bing remains fully dark (0 crawled, 0 in index) 2+ days after its first
non-empty report row. Pushed the one lagging post
(`ai-not-relevant-to-my-business`) to IndexNow as a nudge for Bing/etc —
accepted (200, key file verified live) — but this has no effect on Google
indexing, which is the one that matters most right now.
